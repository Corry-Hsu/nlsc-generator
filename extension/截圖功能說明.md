# 逐行清單分類更新

每行為一組，不需要額外命名。例如：

```text
屏東市光明段 477、512
屏東市龍華段 1385
屏東市光明段 600、601
```

先按「開始查詢定位」，再按「擷取面積」。匯出 Excel 的「清單加總」會有三筆，逐筆結果保留各地號及清單序號；若有擷取失敗，該組標示未完成，不提供不完整合計。

批次截圖按清單順序下載三張：
- 屏東市_光明段_477、512.png
- 屏東市_龍華段_1385.png
- 屏東市_光明段_600、601.png

修改清單後需重新執行查詢定位。截圖依最近一次查詢的分組，且該組所有地號都必須已著色。同一地號可出現在不同組，並分別計入各組。

重新載入擴充功能並重新整理網站後生效。

# NLSC 地段批次截圖（1.1.2）

1. 在 Chrome／Edge 擴充功能管理頁重新載入此外掛，再重新整理國土測繪圖資雲網站。
2. 先完成查詢、著色，再由瀏覽器工具列啟動截圖（詳見第 5 步）。
3. 輸入地號清單，按「開始查詢定位」。多筆地號使用頓號或逗號分隔，例如 `屏東市光明段477、512`。
4. 按「擷取面積」讓地號逐筆著色；也可以使用網站查詢結果的「著色」按鈕。
5. 點 Edge／Chrome 右上角「擴充功能」（拼圖），再點「NLSC 測繪自動化小工具」名稱或圖示，或按 `Alt+Shift+S`，即授權目前分頁並開始截圖。確認權限後圖示顯示 ON；保持網站分頁在前景，等候下載完成。已授權的分頁也可以按面板的「依清單逐行截圖 PNG」。若快捷鍵被其他程式占用，請使用工具列入口。

1.1.2 修正授權流程：`activeTab` 必須由瀏覽器工具列的外掛入口或外掛快捷鍵觸發，網頁內的按鈕無法授予權限。現在工具列入口會直接開始批次截圖；截圖前先做權限預檢，失敗時不移動地圖、不送出下載，並清楚顯示操作入口。預檢圖片只用於確認權限，不下載，也不傳給網站。

由外掛清單查詢時，每行的已著色地號合併成一張圖，同鄉鎮同地段的不同行仍分開處理；未使用外掛清單查詢時，網站手動著色仍依鄉鎮、地段分組，在完整顯示該組著色範圍、四周留白的前提下放大。圖片擷取目前地圖區域，使用目前底圖與圖層，解析度依瀏覽器可視地圖大小與螢幕像素比例而定。

1.1.1 修正地圖容器部分超出畫面時被中止的問題：以實際 OpenLayers viewport 與瀏覽器可視區域的交集取景，重新計算中心與縮放，確保著色地號完整入鏡。小數座標會裁齊邊界，捲軸不納入圖片；版面載入期間有變動時，最多重新取景三次。

若仍無法截圖，狀態列會顯示具體原因，包括地圖座標、視窗尺寸、剩餘可見範圍、版面持續變動或地圖縮放限制。開發者工具 Console 也會記錄失敗詳情。無須為了避免容器輕微溢出而固定將瀏覽器縮放設為 100%。

檔名範例：`屏東市_光明段_477、512.png`。圖片存入瀏覽器設定的下載位置，同名檔案會另取名稱，不覆蓋原檔。若瀏覽器設為每次詢問儲存位置，請依下載提示操作。

截圖會暫時隱藏其他組的地籍著色、外掛面板，停用地圖拖曳縮放，完成或失敗後還原視角與圖層。請先關閉遮擋地圖的網站詳細視窗，執行時不要切換分頁、調整視窗或操作網站圖層。

只支援本次重新整理後經網站一般地號查詢、再著色的地號。其他來源的著色或更新外掛前的既有著色，請重新查詢並著色。沒有鄉鎮資料、無法辨識範圍、地圖載入逾時或檔名過長時會停止並提示；先前已送出的下載會保留。

權限：activeTab 用於點工具列圖示後擷取目前分頁；downloads 用於依地段自動命名下載 PNG。圖片由瀏覽器本機處理。
